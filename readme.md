## 🎯 Project Breakdown

### Week 1: Rule-Based Chatbot

**Objective:** Build a chatbot using if-else conditions and pattern-matching rules to handle user queries without machine learning.

**What I Built:**

- Simple conversational flows for FAQs and greetings
- Rule sets to detect user intent and generate appropriate responses
- Clean, modular code structure for easy expansion

**Key Learnings:**

- Understanding basic chatbot architecture
- Intent mapping and response templates
- Conversation flow design

**Real-World Applications:**

- Website FAQ bots
- Customer support assistants
- Informational chatbots

**📂 Folder:** `Week 1 Rule Based chatbot/`

---

### Week 2: Data Classification using KNN

**Objective:** Implement a K-Nearest Neighbors classifier to perform supervised learning on a dataset and evaluate model performance.

**What I Built:**

- Loaded and preprocessed data in Python
- Implemented KNN classification with configurable k value
- Split data into training and testing sets
- Evaluated performance using accuracy and other metrics
- Visualized results and decision boundaries

**Key Learnings:**

- Supervised learning workflow
- Model training and evaluation
- Hyperparameter tuning (k value selection)
- Evaluation metrics interpretation

**Real-World Applications:**

- Customer segmentation
- Image classification
- Medical diagnosis support

**📂 Folder:** `Week 2 Data Classification using KNN/`

---

### Week 3: Recommendation System

**Objective:** Build a recommendation engine that suggests items to users based on data patterns and feature similarity.

**What I Built:**

- Explored and analyzed datasets to identify relevant features
- Implemented recommendation logic (similarity-based and/or collaborative filtering approach)
- Generated personalized recommendations for sample users/items
- Documented outputs with real-world usage examples

**Key Learnings:**

- Recommendation algorithm fundamentals
- Feature engineering for similarity calculation
- Collaborative vs. content-based filtering
- Measuring recommendation quality

**Real-World Applications:**

- E-commerce product suggestions
- Streaming service recommendations
- Social media friend/follow suggestions

**📂 Folder:** `Week 3 Recommendation System/`

---

### Week 4: OCR (Optical Character Recognition) Project

**Objective:** Extract text from images using Python and OCR tools to understand computer vision and text processing pipelines.

**What I Built:**

- Preprocessed images for optimal text detection
- Applied OCR to extract text from images
- Implemented text cleaning and formatting
- Generated and saved extracted text results
- Captured before/after screenshots

**Key Learnings:**

- Image preprocessing techniques
- Optical character recognition workflows
- Combining computer vision with text processing
- Handling OCR output quality issues

**Real-World Applications:**

- Document digitization
- Receipt/invoice processing
- License plate recognition
- Accessibility tools for printed materials

**📂 Folder:** `Week 4 - OCR project/`

## 🚀 How to Use This Repository

### For Learning:

1. **Browse each Week folder** to see the project structure and documentation
2. **Open project files** in your favorite code editor (VS Code, PyCharm, etc.) to explore and understand the code
3. **Review outputs** (screenshots, extracted text) to see final results
4. **Study the approach** used for each problem and adapt it to your own projects

### For Portfolio/Reference:

- Use this repository as a template for structuring your own internship or learning projects
- Reference individual projects for interview preparation
- Adapt the code and approach for your own datasets and use cases

### To Run Locally:

**1. Clone the repository:**

```bash
git clone https://github.com/awaisqarni2/ai-internship-at-DecodeLabs.git
cd ai-internship-at-DecodeLababs
```

**2. Create a virtual environment (recommended):**

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

**3. Install dependencies:**

- For each project, check the imports in `requirements.txt` or code files
- Common packages: `pandas`, `numpy`, `scikit-learn`, `opencv-python`, `pytesseract`

```bash
pip install pandas numpy scikit-learn opencv-python pytesseract pillow
```

**4. Open and run the code:**

```bash
# Open project files in VS Code, PyCharm, or your preferred code editor
# and run Python scripts directly
python script_name.py
```
